# reso-alert (Resonance Auto Relogin)

레조넌스(한국 PC 클라이언트)를 정해 둔 시각에 **다시 켜서 구글 로그인**하고, 교정 센터의 **일괄 수령·일괄 구매**까지 대신 눌러 주는 Windows용 도구예요.
다음 구매가 끝나는 시각을 화면에서 읽어, 그 시각에 맞춰 다시 접속해요.

> ⚠️ **먼저 읽어 주세요**
> 이 도구는 게임을 자동으로 껐다 켜고 화면을 대신 클릭하는 **자동화 프로그램**이에요.
> 게임 이용약관·운영 정책상 매크로·자동화 프로그램 사용은 제재 대상이 될 수 있어요.
> 사용 여부와 그 결과(계정 제재 포함)에 대한 책임은 사용하는 분에게 있어요. 공식 정책을 꼭 확인하고 쓰세요.
> 이 프로젝트는 게임사와 관계가 없어요.

## 하는 일

| 기능 | 설명 |
|---|---|
| 재접속 | 게임을 끄고(로그인 웹뷰 잔여 프로세스 포함) 다시 켠 뒤, 영상 넘기기 → Sign in with Google → **첫 번째 구글 계정** → 계속 순서로 눌러요 |
| 교정 센터 구매 | 로그인 뒤 프로필 → 교정 센터 → 구매로 들어가 일괄 수령 → 팝업 닫기 → 일괄 구매를 눌러요. 출석 보상 같은 팝업은 바깥 빈 곳을 눌러 닫아요 |
| 구매 시각 반복 | 구매 중인 주문의 '남은 시간'을 Windows 글자 인식으로 읽어, 끝나는 시각에 다시 접속해요. 재료가 부족해 새 구매가 안 걸리면 다음 날 05:00에 다시 봐요 |
| 알림만 모드 | 배지 메뉴에서 '알림 시점에 재실행 끄기'를 누르면 재접속하지 않고, **구매가 끝나는 시각에 작은 알림만** 띄워요(다음 주문 확인 / 다음 날 05시 / 알림 설정 없이 닫기). 직접 받고 다시 구매한 뒤 [다음 주문 확인]을 누르거나 구매 화면을 열어 두면 다음 알림 시각을 맞춰요. 다시 켜려면 '알림 시점에 재실행 켜기'를 누르세요 |
| 1분 전 알림 | 재접속 1분 전에 PC를 쓰고 있으면 게임 창 오른쪽 아래에 알림이 떠요(5분 미루기 / 다음 주문 확인 / 다음 날 / 반복 중지). 포커스를 가져가지 않아요 |
| 업데이트 | 배지 메뉴의 '업데이트 확인'을 누르면 GitHub의 최신 릴리스를 확인하고, 더 새 버전이면 받아서 바꾼 뒤 배지·반복을 새 버전으로 다시 켜요 |
| 타이머 배지 | 게임 창 위에 다음 재접속 시각이 보여요. 누르면 메뉴, 끌면 위치가 기억돼요. 재접속 중 누르는 자리와 겹치면 그동안만 화면 가운데 위로 비켜요 |

## 하지 않는 일 (안전성)

- **인터넷 접속은 '업데이트 확인'을 눌렀을 때만** GitHub(이 저장소의 릴리스)로 해요. 그 밖에는 접속하지 않고, 아무것도 보내지 않아요.
- **게임 메모리를 읽거나 바꾸지 않아요.** 게임 파일도 건드리지 않아요.
- **비밀번호·토큰을 다루지 않아요.** 구글 로그인은 게임 자체 로그인 창에서 이미 로그인된 계정을 고르는 클릭만 해요.
- 게임 로그(`Player.log`)는 **로그인이 끝났는지**만 확인해요. 이 파일에는 계정 정보가 들어 있으니 다른 사람에게 공유하지 마세요.
- 파일은 `%LOCALAPPDATA%\ResonanceAutoRelogin` 폴더에만 써요(설정·기록·임시 이미지·업데이트 백업). 업데이트할 때만 프로그램 폴더의 코드·문서를 바꿔요.
- 자세한 내용은 [SECURITY.md](SECURITY.md)를 보세요.

## 필요한 것

- Windows 10 / 11, **한국어 OCR 언어 팩**(한국어 Windows는 기본 포함. 영문 Windows는 설정 → 시간 및 언어 → 언어 및 지역 → 한국어 추가. `setup`이 확인해 줘요)
- [Python 3.10 이상](https://www.python.org/downloads/) — 설치할 때 **Add python.exe to PATH**를 체크하세요
- 레조넌스 한국 PC 클라이언트, **구글 계정으로 로그인**하는 경우만 지원해요(다른 로그인 방식은 아직 없음)
- 게임은 **16:9 창 모드**로 두세요. 화면 판별이 창 안쪽 16:9 비율 기준이에요

## 설치

```powershell
git clone https://github.com/kktrudxo321/reso-alert.git
cd reso-alert
python -m pip install -r requirements.txt
```

## 처음 설정

1. 게임을 켜고, 평소 쓰는 자리·크기로 게임 창을 둬요.
2. 아래 명령을 실행해요. 게임 경로를 찾고, **지금 게임 창 위치를 저장**해요(재접속 때 이 자리로 옮겨요).

```powershell
python -m resonance_auto setup
```

설정은 `%LOCALAPPDATA%\ResonanceAutoRelogin\settings.json`에 있어요. 메모장으로 고쳐도 돼요.

| 항목 | 기본값 | 설명 |
|---|---|---|
| `game_exe` | (자동 찾기) | 게임 실행 파일 경로 |
| `player_log` | `%USERPROFILE%\AppData\LocalLow\临界\레조넌스\Player.log` | 게임 로그 위치(로그인 완료 확인용) |
| `window_rect` | setup 때 창 위치 | `[x, y, 너비, 높이]`. `null`이면 창을 옮기지 않아요 |
| `relaunch` | `true` | 알림 시점에 재실행. `false`면 구매가 끝나는 시각에 알림만 띄워요(배지 메뉴에서 켜고 끌 수 있어요) |
| `buy_automation` | `true` | 교정 센터 일괄 수령·구매까지 할지 |
| `notify_before_restart` | `true` | 1분 전 알림 |
| `screensaver_control` | `false` | 재접속 중 화면 보호기를 잠깐 끄고 끝나면 다시 켜기(PC 설정을 건드려서 기본 끔) |
| `fallback_minutes` | `31` | 다음 주문 시각을 못 읽었을 때 다시 시도하는 최대 간격 |

## 사용

```powershell
python -m resonance_auto once                 # 지금 한 번 재접속
python -m resonance_auto start                # 구매 완료 시각마다 반복
python -m resonance_auto start --interval 31  # 31분마다 반복
python -m resonance_auto start --delay 10     # 첫 재접속을 10분 뒤에
python -m resonance_auto stop                 # 반복 중지
python -m resonance_auto badge                # 게임 창 위 타이머 배지
python -m resonance_auto status               # 지금 예약 보기
python -m resonance_auto update               # 최신 릴리스로 업데이트
```

끄려면 배지 메뉴의 **프로그램 종료**를 누르세요(반복 재접속을 멈추고 배지도 닫아요). 명령으로는 `python -m resonance_auto stop`(반복만 중지)이에요.

창 없이 조용히 돌리려면 `python` 대신 `pythonw`를 쓰세요. 예: `pythonw -m resonance_auto start`

배지를 PC를 켤 때마다 띄우고 싶으면, `Win + R` → `shell:startup` 폴더에 바로 가기를 만들어요.
대상: `pythonw.exe -m resonance_auto badge`, 시작 위치: 이 폴더.

기록은 `%LOCALAPPDATA%\ResonanceAutoRelogin\relogin.log`에 남아요(배지 메뉴 → 기록 열기).

## 주의할 점

- 재접속하는 동안 게임 창을 잠깐 '항상 위'로 두고 **실제 마우스로 클릭**해요. 그 사이 마우스를 움직이면 클릭이 빗나갈 수 있어요. PC를 쓰는 중이면 1분 전 알림에서 미루세요.
- 화면 보호기가 켜져 있으면 클릭이 게임에 전달되지 않아요. 필요하면 `screensaver_control`을 켜세요.
- **처음 한 번은 게임에서 직접 구글 로그인**을 해 두세요. 구글 로그인 창에 계정 목록이 떠야 자동으로 고를 수 있어요. 이메일·비밀번호 입력 화면이나 '본인 확인' 같은 추가 화면이 뜨면 자동으로 넘길 수 없어요(비밀번호는 다루지 않아요).
- 구글 계정 선택 창에서 **첫 번째 계정**을 눌러요. 계정이 여러 개면 게임용 계정이 맨 위에 오게 하세요.
- 구글 로그인 창은 Windows 테마(어둡게/밝게)를 따라 색이 바뀌어요. 두 테마 모두 지원해요.
- 게임 업데이트로 화면이 바뀌면 판별이 틀릴 수 있어요. 이상하면 `relogin.log`를 첨부해 이슈로 알려 주세요(로그에는 시각·진행 단계, 오류가 나면 오류 내용이 있어요. 올리기 전에 한 번 확인하세요).
- 게임을 관리자 권한으로 실행하는 경우 이 프로그램도 관리자 권한으로 실행해야 해요.
- 명령은 이 폴더(저장소 폴더)에서 실행하세요.
- 로그인이 5분 안에 안 되면 처음부터 다시, 최대 5번까지 해요.
